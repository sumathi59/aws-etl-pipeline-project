# AWS ETL Pipeline Project

## Overview
This project demonstrates an end-to-end ETL pipeline using AWS services.

## Technologies Used
- AWS S3
- AWS Glue (PySpark)
- AWS Athena
- Python

## Architecture
1. Raw data stored in S3
2. AWS Glue processes data
3. Processed data stored back in S3
4. Athena used for querying

## Features
- Data ingestion from CSV
- Data transformation using PySpark
- Scalable processing using AWS Glue
- Querying using Athena

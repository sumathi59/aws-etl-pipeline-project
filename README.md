# AWS ETL Pipeline Project

## 📌 Overview
This project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline built using AWS services. It processes raw CSV data, performs transformations using PySpark, and enables querying for analytics.

---

## 🛠️ Technologies Used
- AWS S3
- AWS Glue (PySpark)
- AWS Athena
- Python

---

## 🏗️ Architecture
1. Raw data is stored in AWS S3  
2. AWS Glue processes and transforms the data  
3. Processed data is written back to S3  
4. AWS Athena is used for querying and analytics  

---

## ⚙️ Features
- Data ingestion from CSV files  
- Data cleaning and transformation using PySpark  
- Scalable ETL pipeline using AWS Glue  
- Querying processed data using Athena  

---

## 🚀 Project Highlights
- Built a scalable ETL pipeline using AWS services  
- Implemented data transformation using PySpark  
- Designed a basic data lake architecture (raw → processed layers)  
- Improved data accessibility for analytics
